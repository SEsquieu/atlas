# Support

Atlas is pre-v0.1 alpha software.

## Community and development questions

Use GitHub Discussions when enabled. Use an issue for reproducible bugs or focused feature proposals. Search existing reports first and remove credentials, images, transcripts, memory, and customer data.

## Security

Do not report vulnerabilities publicly. Follow [`SECURITY.md`](./SECURITY.md).

## Closed-alpha testers

Invited testers will receive a private reporting channel, supported APK version, known-issues list, and response expectations with each build. Those operational details should not be embedded in the open runtime.

## Unsupported uses

The alpha is not supported for unattended automation, emergency response, medical/legal/safety authority, production industrial control, or any workflow where a mistaken model response or action can cause harm.

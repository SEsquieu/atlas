## The Model Is Not the Agent

Atlas is an Android-native physical-agent runtime. The phone owns persistent identity, session state, physical observations and freshness, voice delivery, tools and execution policy, memory, routing, lifecycle, provenance, and failure handling. Local, LAN, BYOK cloud, and future managed models are replaceable reasoning capabilities.

## Highlights

- Native Android foreground-session runtime with manual and opt-in Live Context modes.
- CameraX observation pipeline with purpose-specific image budgets, hashing, and private storage.
- Motion-aware freshness policy that fails closed for high-risk current-world questions.
- Push-to-talk, streaming sentence TTS, barge-in, and delivery-aware conversation continuity.
- Ordered fast/vision/reasoning/fallback routes for OpenAI-compatible endpoints.
- Compact prompt compilation for constrained on-device models without making it the global prompt.
- Typed, bounded, confirmation-gated tools with explicit unknown execution state.
- Durable SQLite messages, turns, observations, memory, summaries, clarification, speech segments, tools, and event provenance.
- Soft-timeout diagnostics that preserve late responses without speaking them into a stale interaction.
- Session export, deletion, and media retention controls.
- Provider-independent TypeScript Core contracts, event replay, scenario harnesses, and behavioral regression fixtures.

## Known limitations

- Alpha software: not for unattended, emergency, safety-critical, or production use.
- Endpoint abilities are user-declared; empirical characterization and automatic routing are not implemented.
- Kotlin Android and TypeScript Core express related contracts but do not yet share one generated schema or runtime.
- Local multimodal support depends on the endpoint/model/projector configuration.
- Android lifecycle, Bluetooth audio, and process-death behavior still require broader device evidence.
- Packaged embeddings, evolving personality, and production managed inference are deliberately deferred.

# Alpha.35: host verification and source retention

Status: preparing qualification. Tracks [#72](https://github.com/SEsquieu/atlas/issues/72). Latest delivered APK remains alpha.34 until signed delivery is recorded here.

## Changes

- Exact count values are normalized and bounded before candidate execution; nonnumeric, negative or fractional counts return indexed actionable rejection. Integer values and historical decimal strings are supported.
- Input/select reports include requested/actual values, HTML type, min/max/step and validity. Range clamping and numeric-input sanitization remain real browser behavior.
- capture_dom stores a uniquely named host fingerprint; assert_dom_equal/not_equal compare later output against it using the exact same selector. At most eight keys, 256 matched roots and 65536 HTML characters per capture. Missing/oversized output fails without truncation. Keys exist only within that check, including reloads. Exact outerHTML comparison excludes canvas pixels, computed styles and JS-only state; select stable content and avoid timestamps/run counters.
- Durable task source reads are recovered independently of lossy transcript summaries, matched against the latest pending candidate or current live bytes, and carried forward only when the range is missing from selected messages. Stale/foreign/failed reads are excluded. The extra source block is bounded to 8000 characters by default (hard ceiling 16000) and retains file hashes, offsets, base/parent identity and original operation IDs. JSON escaping and surrogate boundaries count toward the cap. It is untrusted data and grants no execution authority.
- Context diagnostics report retainedSourceCharacters for subsequent phone benchmarks. No general token or latency improvement is claimed yet.

## Phone cycle

Ask Atlas to improve the existing MazeGen app using its judgment. For claimed seed repeatability, capture stable maze DOM, regenerate with the same seed and compare equality; use another seed and inequality where appropriate. For rejected-input preservation, capture output before an input the control can actually represent, then verify an error plus unchanged output. A status message or count alone does not establish these properties. Test reload separately when claiming persistence.

Export the session and compare repeated reads, retainedSourceCharacters, provider/compaction latency, token use and activation wall time. The staged core-0.1.1 guidance from alpha.34 remains unselected until explicit user approval; this host build does not activate or replace it.

# Technical essay outline: The Model Is Not the Agent

1. **The category error** — why a model conversation with tools is not yet a persistent agent.
2. **Put the boundary in a phone** — the phone as body: camera, microphone, speakers, sensors, battery, thermals, network, foreground lifecycle, and user presence.
3. **What survives a brain transplant** — identity, session continuity, memory authority, permissions, task state, observations, and provenance across provider swaps.
4. **Physical evidence expires** — observed time versus interpreted time; motion, stability, media suitability, and why intelligence cannot repair stale evidence.
5. **Determinism before inference** — route eligibility, freshness, event ordering, scopes, budgets, and policy as code; use models only for ambiguous meaning.
6. **Execution is not text** — proposals, confirmation, idempotency, running/complete/failed/unknown outcomes, and the danger of treating timeout as non-execution.
7. **Voice changes the state model** — streaming, sentence delivery, interruption, what the user actually heard, and why a transcript alone is insufficient.
8. **Small brains reveal architecture** — compact prompt compilation and the Qwen 3.5 2B tests: retrieval success, latency constraints, and unsupported causal bridges.
9. **Observability without chain-of-thought** — event provenance, route/latency/token evidence, session export, and late responses as alpha learning surfaces.
10. **Two implementations, one direction** — native Kotlin runtime versus provider-independent TypeScript Core; what is shared today and what still needs contract parity.
11. **Minimum purchased intelligence** — characterize recall, tools, vision, entailment, latency, cost, and privacy; route to the least intelligence that safely completes the turn.
12. **What Atlas refuses to fake** — no premature embeddings, personality mythology, managed-backend coupling, or claims unsupported by physical-device evidence.
13. **The open-source invitation** — the interesting work begins where inference ends: durable agency, physical truth, consequences, and lifecycle.
